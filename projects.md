### ternip

**Description** — Accelerator for MatmulFree LLM algorithm

- Under lead of Ethan Sifferman(PhD Student) and Dustin Richmond(Assistant Professor) within UCSC HSC
- Implemented changes to handle parameterized vectorized operations of operations to increase
- Implemented weight compression and decompression
- Contributed to architecture design with RMS changes to account for arbitrary length vectors
- Deployed on U250 FPGA
- Working on TSMC6 tapeout

- **Stack/Tools:** Vivado, Yosys, Verilator, System Verilog, Python
- **Links:** [GitHub](https://github.com/sifferman/ternip/) · [Demo (Hopefully soon)](#)
