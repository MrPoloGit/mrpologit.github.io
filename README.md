# mrpologit.github.io

This is my personal website hosted using github pages.

## Running locally

This site is built with [Jekyll](https://jekyllrb.com/) and requires Ruby (see `.ruby-version` for the expected version).

1. Install dependencies:
   ```
   bundle install
   ```
2. Start the local server:
   ```
   bundle exec jekyll serve
   ```
3. Open [http://localhost:4000](http://localhost:4000) in your browser.

The site will rebuild automatically when files change. Use `bundle exec jekyll serve --livereload` to also refresh the browser automatically.
